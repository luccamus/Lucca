# SESI SENAI — Detector Facial

O projeto **Detector Facial SESI SENAI** tem como objetivo desenvolver um sistema capaz de identificar rostos utilizando uma câmera. A aplicação utiliza tecnologias de visão computacional para detectar automaticamente a presença de uma pessoa diante da câmera.

O sistema foi desenvolvido com **HTML, CSS e JavaScript**, utilizando ferramentas de detecção facial. Ao ativar a câmera, o programa analisa a imagem em tempo real e verifica se existe um rosto no campo de visão.

A proposta do projeto é demonstrar, de forma prática, como a tecnologia de **inteligência artificial e visão computacional** pode ser aplicada no desenvolvimento de sistemas modernos. Além disso, o projeto contribui para o aprendizado de programação, integração com câmera e utilização de bibliotecas externas.

Durante o desenvolvimento, foram trabalhados conceitos como manipulação do DOM, eventos em JavaScript, acesso à câmera do dispositivo e processamento de imagens. Dessa forma, o projeto apresenta uma aplicação simples, mas demonstra o potencial da tecnologia de reconhecimento e detecção facial.
